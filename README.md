# Manas Meter

Estimates a student's mental health score (0–10) from screen time, sleep, study, activity and stress.

- **Frontend:** `index.html`, `style.css`, `script.js`
- **Backend:** `main.py` (FastAPI) with `Mental_Health_Model.pkl`

Run the API: `pip install -r requirements.txt` then `uvicorn main:app --reload`.
Open `index.html` in a browser for the UI.
